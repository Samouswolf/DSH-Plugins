# 技术交底书

## 发明名称

一种基于语义聚类与命中反馈的智能体记忆优化方法及系统

## 技术领域

本发明涉及人工智能技术领域，特别涉及一种面向AI智能体的长期记忆优化方法，包括语义聚类分级加载、语义压缩精简和基于命中反馈的智能预加载机制。

---

## 一、背景技术

### 1.1 现有技术概述

随着大语言模型（LLM）驱动的AI智能体广泛应用，智能体需要在多轮对话和长期运行中保持上下文连贯性和知识积累。现有的智能体记忆管理方案主要包括：

**（1）MemGPT/Letta方案**
- 采用操作系统式分层记忆（主存/外存/归档）
- 智能体通过函数调用自主管理记忆迁移
- 缺点：无语义分组，全量检索效率低；无自动压缩机制；无使用反馈学习

**（2）Mem0方案**
- 基于向量数据库存储记忆
- 支持语义搜索和记忆去重
- 缺点：无分级加载策略；无压缩合并机制；无预加载优化

**（3）LangChain Memory方案**
- 提供对话缓冲、摘要、向量存储等记忆组件
- 缺点：无自主学习能力；无聚类分组；无自动优化机制

### 1.2 现有技术的缺陷

| 缺陷 | 描述 |
|------|------|
| 全量加载 | 启动时加载所有记忆，token消耗大 |
| 无语义分组 | 记忆平铺存储，检索效率低 |
| 无压缩机制 | 记忆持续增长，无法精简 |
| 无使用反馈 | 不学习用户的使用模式，预加载命中率低 |
| 信息丢失风险 | 简单截断或丢弃导致重要信息丢失 |

## 二、发明内容

### 2.1 发明目的

针对现有技术的不足，本发明提出一种基于语义聚类与命中反馈的智能体记忆优化方法，实现：

1. 启动时按需加载，降低token消耗
2. 记忆语义压缩，保留决策骨架不丢失关键信息
3. 基于使用反馈的智能预加载，越用越准

### 2.3 第一层：基于语义聚类的分级加载方法

#### 2.3.1 聚类构建

**步骤S1：特征向量提取**

对每条记忆M，通过信号提取器生成特征向量V(M)，提取维度包括：
- 领域信号：从文本中提取领域相关词汇
- 意图信号：提取动作词、疑问词
- 实体信号：提取实体名词
- 模式信号：提取数字、标点等结构特征

将多维特征拼接为固定维度的特征向量。

**步骤S2：K-Means++聚类**

采用K-Means++初始化策略：
1. 随机选择第一个中心C1
2. 对每个样本x，计算D(x)² = min||x - Ci||²
3. 按概率P(x) = D(x)² / ΣD(x)²选择下一个中心
4. 重复直到选择K个中心

迭代更新中心：
```
对每个簇Sj：
  新中心 = (1/|Sj|) * Σ V(xi), xi ∈ Sj
```

空簇处理：当某簇无成员时，从最大簇中选择距离当前中心最远的点作为新中心。

**步骤S3：簇级别划分**

根据簇内记忆的标签特征，将簇划分为三个级别：

| 级别 | 标签特征 | 加载策略 | 典型内容 |
|------|----------|----------|----------|
| L0 | 包含"规则""流程""约束"等关键词 | 启动时必加载 | 核心规则、工作流约束、全局策略 |
| L1 | 包含具体业务领域标识或实体名 | 提到相关话题时加载 | 领域特定记忆、事件记录、操作档案 |
| L2 | 无明确标签或深层细节 | 具体问题触发时加载 | 历史决策细节、调试记录、追溯信息 |

#### 2.3.2 按需加载

**L0核心加载**：系统启动时，加载所有L0级别簇的记忆。

**L1话题加载**：当用户输入中检测到话题信号（业务领域标识、技术关键词）时，通过语义预测找到最匹配的L1簇，加载该簇记忆。

**L2深层加载**：当具体问题无法从L0/L1记忆回答时，触发L2加载。

#### 2.3.3 过期检测与自动重建

维护脏标记`_cluster_dirty`，在以下操作中置为True：
- 新增记忆（ingest）
- 记忆淘汰（evolve）
- 记忆巩固（consolidate）

启动时检测：
```
if |当前记忆数 - 索引记录数| / 索引记录数 > 0.2:
    触发重建
if _cluster_dirty == True:
    触发重建
```

### 2.4 第二层：基于语义压缩的记忆精简方法

#### 2.4.1 三级压缩策略

**策略一：去重压缩（阈值0.92）**

计算簇内记忆两两相似度，相似度>0.92的记忆视为重复，保留综合价值最高的一条。

综合价值计算：
```
score = lifetime * 0.5 + access_count * 0.3 + recency * 0.2
```

**策略二：贪心分组压缩（阈值0.70）**

在每个簇内，以簇中心为参考，将相似度>0.70的记忆分为一组，每组合并为一条浓缩记忆。

分组算法：
```
1. 按与簇中心的相似度降序排列
2. 取第一个记忆作为组代表
3. 遍历剩余记忆，与组代表比较相似度
4. 相似度>阈值的加入当前组
5. 当前组无法继续扩展时，开始新组
```

**策略三：时间线合并（窗口72小时）**

同一业务领域的多条时间线记录，若时间间隔<72小时，合并为一条时间线记忆。

#### 2.4.2 信息保留策略

合并后的记忆保留以下关键信息：
- 业务领域标识（必须保留）
- 异常事件描述和处理方案（必须保留）
- 关键参数和决策原因（必须保留）
- 时间标签（temporal_tags取并集）
- 情景关联（episode_id取第一个非空值）
- 父子关系（parent_id/child_ids合并去重）

非关键表述进行精简，保留决策骨架：
```
原文: "实体A的状态检测使用矩形判定方式，触发事件1加3分，冲突事件比较参数值决定结果"
精简: "状态检测:矩形判定,事件1+3分,冲突比参数"
```

#### 2.4.3 可追溯性保障

压缩后的记忆记录来源ID列表：
```json
{
  "source_ids": ["mem_001", "mem_002", "mem_003"],
  "compressed_text": "状态检测:矩形判定,事件1+3分,冲突比参数",
  "compression_method": "greedy_group"
}
```

原始记忆移入归档目录，支持按ID恢复。

#### 2.4.4 无损压缩的信息完整性保障

采用token级Jaccard相似度判断信息唯一性：

```
tokenize(text) → [英文词, 中文二元组, 数字串]

Jaccard(A, B) = |tokens(A) ∩ tokens(B)| / |tokens(A) ∪ tokens(B)|
```

当Jaccard(A, B) < 0.5时，认为B包含A未覆盖的独有信息，保留为补充内容。

### 2.5 第三层：基于命中反馈的智能预加载方法

#### 2.5.1 命中关联图

构建话题→簇的命中关联图G = (V, E)：
- 节点V：话题词（业务领域标识、技术关键词）
- 边E：(话题, 簇ID) 的命中次数

```
record(topic, cluster_id):
    edges[(topic, cluster_id)] += 1
    topic_totals[topic] += 1
```

带索引查询优化：
```
_topic_index: {topic → set[cluster_id]}
查询复杂度: O(topics) 而非 O(topics * edges)
```

#### 2.5.2 话题提取

从用户输入中提取话题信号：
- 业务领域标识匹配：通过可配置的领域词典进行匹配
- 技术关键词匹配：通过可配置的技术词典进行匹配
- 短英文关键词（≤3字符）使用词边界匹配，避免误匹配

#### 2.5.3 智能预加载

启动时根据命中图预加载高频簇：
```
1. 提取当前上下文的话题信号
2. 查询命中图，获取每个话题的高频关联簇
3. 按命中次数降序排列
4. 跳过已加载的L0核心簇
5. 预加载剩余高频簇
```

#### 2.5.4 命中率计算与自动调节

命中率计算：
```
hit_rate = _hit_count / _preload_count
```

其中：
- `_preload_count`：每次预加载操作+1
- `_hit_count`：预加载的簇被实际使用时+1

自动禁用机制：
```
if preload_count >= 3 and hit_rate < 0.5:
    禁用该(话题, 簇)组合
    持久化禁用状态到JSON
```

禁用状态持久化，重启后保持，避免重复学习失败的组合。

## 五、具体实施方式

### 5.1 系统初始化

```python
class MemoryOptimizationSystem:
    def __init__(self):
        # 第一层：语义聚类
        self.semantic_cluster = SemanticCluster(n_clusters=12)
        self.cluster_loader = ClusterLoader()

        # 第二层：记忆压缩
        self.compressor = MemoryCompressor(
            dedup_threshold=0.92,
            group_threshold=0.70,
            timeline_window_hours=72
        )

        # 第三层：智能预加载
        self.hit_graph = HitGraph()
        self.topic_extractor = TopicExtractor()
        self.smart_loader = SmartLoader(self.hit_graph, self.cluster_loader)
```

### 5.2 启动流程

```python
def boot(self):
    # Step 1: 加载L0核心簇
    core_memories = self.load_core_memories()

    # Step 2: 检查聚类索引过期
    if self._cluster_dirty or self._pool_size_changed(0.2):
        self.rebuild_cluster_index()

    # Step 3: 根据命中图预加载高频簇
    hot_clusters = self.hit_graph.get_preload_clusters(
        self.recent_topics, threshold=0.5
    )
    self.smart_loader.preload_for_context(self.recent_topics)
```

### 5.3 对话中的记忆管理

```python
def on_user_input(self, text):
    # 话题提取
    topics = self.topic_extractor.extract_topics(text)

    # 按需加载L1话题簇
    for topic in topics:
        cluster_id, similarity = self.semantic_cluster.predict(topic)
        if self.semantic_cluster.clusters[cluster_id].level == "L1":
            memories = self.load_topic_memories(topic)
            self.learn_hit(topic, [cluster_id])

    # 记忆压缩（定期触发）
    if self.should_compress():
        self.compress()
```

### 5.4 记忆压缩执行

```python
def compress(self):
    for cluster_id, cluster in self.semantic_cluster.clusters.items():
        members = self.get_cluster_members(cluster_id)

        # Step 1: 去重
        deduped = self.compressor.deduplicate(members)

        # Step 2: 贪心分组
        groups = self.compressor.greedy_group(deduped, cluster.centroid)

        # Step 3: 合并
        for group in groups:
            if len(group) > 1:
                compressed = self.compressor.merge_group(group)
                self.compressor.archive_originals(group)
                self.add_compressed(compressed)
```

### 独立权利要求

**权利要求1**：一种基于语义聚类的智能体记忆管理方法，其特征在于，包括以下步骤：

S1. 对智能体的记忆集合中的每条记忆提取特征向量；
S2. 采用K-Means++算法对所述特征向量进行聚类，得到K个记忆簇；
S3. 根据每个记忆簇的标签特征，将记忆簇划分为核心级L0、话题级L1和深层级L2三个级别；
S4. 系统启动时加载所有L0级别记忆簇的记忆；
S5. 当用户输入中检测到话题信号时，通过语义预测找到最匹配的L1级别记忆簇并加载；
S6. 当L0和L1级别记忆无法满足需求时，触发L2级别记忆的加载。

**权利要求2**：一种基于语义压缩的智能体记忆精简方法，其特征在于，包括以下步骤：

S1. 对同一记忆簇内的记忆计算两两相似度，相似度超过第一阈值的记忆去重，保留综合价值最高的一条；
S2. 以簇中心为参考，将相似度超过第二阈值的记忆分为一组；
S3. 将每组内的多条记忆合并为一条浓缩记忆，保留业务领域标识、事件描述、关键参数和决策原因；
S4. 将合并前的原始记忆移入归档目录，支持按来源ID恢复。

**权利要求3**：一种基于命中反馈的智能体记忆预加载方法，其特征在于，包括以下步骤：

## 七、创新点总结

| 序号 | 创新点 | 对比现有技术的进步 |
|------|--------|-------------------|
| 1 | 三级语义聚类加载(L0/L1/L2) | 现有技术全量加载，本发明按需分级加载，token降低73.8% |
| 2 | 无损语义压缩(去重+贪心分组+时间线合并) | 现有技术无压缩或简单截断，本发明保留决策骨架，信息零丢失 |
| 3 | 命中学习+自动禁用机制 | 现有技术无反馈学习，本发明基于使用数据自动优化预加载 |
| 4 | 聚类索引过期检测+自动重建 | 现有技术无索引维护，本发明自动检测数据漂移并重建 |
| 5 | token级Jaccard相似度的信息唯一性判断 | 现有技术用字符集重叠（对中文等非空格分隔语言失效），本发明用token级Jaccard |
