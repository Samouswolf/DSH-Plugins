# DNA系统效率+精准度优化方案

## 优化目标
1. 聚类质量提升（减少重复标签、合并小簇）
2. 向量编码精度提升（TF-IDF替代字符频率hash）
3. 话题提取精准度提升（智能分词+权重）
4. 启动效率进一步优化

## 优化项

### 1. 向量编码优化
- 当前: 字符频率hash（128维，太粗糙）
- 优化: TF-IDF加权向量（128维，语义区分度高）
- 效果: 聚类质量↑，检索精准度↑

### 2. 聚类参数优化
- 当前: K=12固定，最小簇无限制
- 优化: 自适应K值（根据记忆数动态调整），最小簇合并
- 效果: 减少碎片簇，聚类更合理

### 3. 簇标签生成优化
- 当前: 取高频词作为标签
- 优化: TF-IDF提取关键词 + 去重合并
- 效果: 标签更准确，不重复

### 4. 话题提取优化
- 当前: 简单正则分割
- 优化: 基于词典的智能匹配 + 权重排序
- 效果: 预加载精准度↑

### 5. L0/L1划分优化
- 当前: 基于标签关键词
- 优化: 基于簇大小+能量均值+访问频率
- 效果: 核心记忆更精准
